# AGENTS.md

The operating rules for this repository live in [`CLAUDE.md`](CLAUDE.md).

This file exists so that an agent following either convention finds them without
searching. It is a pointer rather than a copy, deliberately: two complete rule
files in one repository would be two authorities for the same fact, which is
exactly what rule [C2](method/rules.md#c2) forbids — and a repository that broke
its own rule in its own root would not be worth reading.
